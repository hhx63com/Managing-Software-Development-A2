Introduction of Element Quantity and Element Attachment

Element amount refers to the strength of element attachment, which affects the duration and effect of element reaction. Element attachment refers to the existing state of elements on the target.

Some environments or attacks by fire/water/grass/thunder/ice elements will leave "traces" of the corresponding elements to make the target attach elements, and the element reaction occurs when this "trace" meets other elements.

For example, after the fire element is attached to the target, it can trigger a reaction with other elements (such as ice and water).

In particular, the attachment of ice elements will reduce the movement speed and attack speed.

Element attachment always carries the amount of elements, which will be naturally consumed over time or consumed by element reaction.

The "strong and weak elements" are often used to describe the amount of elements, in which the amount of elements of "strong elements" is twice that of "weak elements".
